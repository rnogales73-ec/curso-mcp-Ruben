# Quickstart: Conversor de Temperatura

## Requisitos Previos
- Tener instalado `uv`.
- Entorno del proyecto sincronizado:
  ```powershell
  uv sync
  ```

## Ejecución de Pruebas
Para ejecutar la suite de pruebas automatizadas:
```powershell
uv run pytest test_conversor.py
```

## Ejecución del Conversor Interactivo
Para iniciar el menú de consola:
```powershell
uv run python conversor_temperatura.py
```
